# Lane L0 (contracts) logs

## Contents

Verbatim `.log` output from the contract lane L0 of Slice 12: RED runs for
governed activation, pattern, taxonomy, locale, template, related-content,
registry, error-catalog, refusal, preflight and key-match contract tests
(`red-*`), the GREEN runs that followed (`green-*`), and focused Vitest and
`tests/contracts` runs.

## Ownership

Lane L0 owns these logs; they are cited by `lane-l0-report.md` in the parent
directory. They are observations of single runs, not acceptance evidence.

## Extension

Add a new log for a new run, named `<red|green>-<subject>.log` or
`<tool>-<subject>.log`, and cite it from the lane report. Never rewrite an
existing log.

## Conventions

Keep output unedited, including failures, and free of credentials, tokens and
personal data. A RED log records the failing assertion; classify harness
failures separately from missing-feature failures in the report.
