## Ownership

The root orchestrator (`claude_root`) writes the briefs. A brief states intent at
launch and is superseded by the lane's report in the parent directory for what
actually happened.

## Extension

Add `<lane>.md` before launching a lane, record the claim in `../LANES.md`, and
refer to `docs/handoffs/2026-10-14-claude-s12/lane-rules.md` for the binding
rules instead of copying them. Do not edit a brief after launch; write a new
one for a follow-up.

## Conventions

Name files, decisions (DEC numbers) and spec paths exactly. Contain no
credentials, tokens or personal data.
