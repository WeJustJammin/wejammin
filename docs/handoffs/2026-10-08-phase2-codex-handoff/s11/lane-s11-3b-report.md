## Design (override welcome)
- Request keys are exactly the S11-4 contract (NOTES "WORKER <-> SQL CONTRACT"); responses are the contract resources key-for-key; refusals are P0001 whole-message tokens, structured members in a JSON-OBJECT DETAIL from the DEC-159 set; a stale frozen manifest COMMITS the review invalidation and answers the committed-refusal envelope {kind:'refusal', reasonCode:'dependency_changed', details:{dependencyHash}} (stored with the reservation, replayed byte-identical).
- Order for 07/09: structure (all field pointers together) -> step-up -> concealment/authority (404 NOT_FOUND via cms_preview_scope_holds, 403 capability_missing, 403 separation_of_duties) -> lock order positions 0-1 (entry FOR SHARE, publisher + counted deciders' authority FOR SHARE, capability re-proved) -> idempotency reservation -> positions 4-5 (schema version FOR SHARE, latest review FOR UPDATE) -> CAS (VERSION_MISMATCH) / state (CONFLICT) -> command specific checks -> committed dependency refusal -> preflight -> effects.
- The reservation hashes `p_request - 'evidence'` (the proof is server-built; a lost-response retry carries a freshly evaluated proof and must replay, not IDEMPOTENCY_MISMATCH). NOTES entry sent to S11-3a (cms_submit_review should do the same).
- The approved review is the revision's LATEST review (E2 order). A revision's derived state is not the gate (a published revision must stay schedulable for unpublish / expire / archive and for other audiences): the review state is.
- CMS-03B-07 echoes localDateTime / resolvedUtc exactly as submitted (the Worker's `accept` compares them verbatim); fractions are limited to microseconds (the stored timestamp precision), so >6 fraction digits is VALIDATION_FAILED at the pointer (the zod contract admits 9: flagged below).
- Executor: cancellation never happens in execute (DEC-158(d)): a revoked/invalidated approval, including an archived entry, blocks with approval_invalidated; stale/mis-bound/absent proof (DEC-158(c)) is retried on the ladder instead of raised (a raise would strand the lease for five minutes); the creator's publisher grant is checked BEFORE the preflight (so publisher_authority_ended is reachable) and MFA is never rechecked (DEC-120); a stale frozen manifest invalidates the review (dependency_changed) and blocks.
- ClaimedSchedule.correlationId is derived deterministically from (schedule, lease) (cms_schedule_correlation) because ExecuteScheduleRequest carries no correlation.
- Accessibility summary (DEC-159 (5)) via S11-3a's recorder in 07, 09 and 20 (any verified proof, any outcome). The recorder's event_id is NOT NULL: for commands without an outbox event (07, blocked/retried 20) I pass a fresh effect id (join key is subject + correlation). Request to S11-3a to make event_id nullable is in NOTES.
