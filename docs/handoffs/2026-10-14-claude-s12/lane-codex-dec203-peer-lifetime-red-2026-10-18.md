## Peer/probe terminal and premise boundaries

Real peers use allowHalfOpen, a nonce-bound socket frame with deliberately wrong
PID and a closed owned IPC stop protocol. PID is read independently from the
spawned ChildProcess, not from the frame. End/close barriers are registered before
stop; peer streams and exact code0/null child close are awaited. Deadline signaling
is only for a captured child with matching current parent/UID/start identity,
synchronously checked before its positive PID; no unrelated PID/group is targeted.
Stop is memoized, so body/finalizer cannot duplicate a send. Listener/socket/child
cleanup attempts all operations and retains all errors, including already-exited
nonzero children. No arbitrary sleep is used as a liveness/drain proof.

The probe child accepts only the two fixed modes. Exact rooted output basenames,
canonical independently read artifact records/current UID, and before/after load
comparison precede native calls. It has no caller-PID/raw-fd action protocol.
Its full /proc/self/fd inventory records descriptor number PLUS target/device/
inode/mode, discarding only the already-closed readdir self-descriptor. Actual
peer resources are held stable during the comparison. Native receiver crashes
remain child failures, never main-process success. Completion is nonce/mode bound,
acknowledged, and emitted only after all attempted internal cleanup; parent also
awaits child/stream closure. Any nonzero probe is still a positive-case failure
and conservatively quarantines outer artifacts; unavailable is never acceptance.

The LC02 undestroyed accepted Socket/real Pipe/positive descriptor assertion and
LC03 exact natural descriptor reuse are explicit prerequisite controls. If those
fail, root must classify a fixture premise failure, not count kernel contract RED.
The copied-method owner tests are private registry integrity, not authorization
against arbitrary same-process code or cross-process process-lifetime proof.
